SentinelRisk is a production-grade fraud detection system that combines:
- 🔬 **End-to-end Data Science** — EDA, SMOTE, LightGBM training, and SHAP explainability in a Jupyter Notebook
- ⚡ **Real-time API** — FastAPI backend serving fraud predictions with per-feature SHAP explanations
- 🖥️ **Enterprise Dashboard** — React + Tailwind CSS dark-mode UI with a live transaction feed, risk meter, and SHAP waterfall chart

## 🚀 Quick Start

### Prerequisites

- Python 3.10+
- Node.js 18+
- Jupyter Lab or VS Code with Jupyter extension

---

## Step 1: Train the Model (Jupyter Notebook)

### 1.1 Get the Dataset

Download the IBM Credit Card Fraud dataset from Kaggle:

```bash
# Option A: Kaggle CLI
pip install kaggle
kaggle datasets download ealtman2019/ibm-transactions-for-anti-money-laundering-aml
unzip ibm-transactions-for-anti-money-laundering-aml.zip -d notebooks/

# Option B: Manual download
# Visit: https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml
# Download card_transaction.v1.csv and place it in the notebooks/ directory
```

### 1.2 Run the Notebook

```bash
# Install Jupyter and notebook dependencies
pip install jupyter lightgbm shap imbalanced-learn scikit-learn pandas numpy matplotlib seaborn joblib

# Launch Jupyter
cd notebooks/
jupyter lab sentinel_risk_training.ipynb
```

Run all cells from top to bottom. The final cell exports:
- `backend/lgbm_ibm_fraud_model.pkl` — trained LightGBM classifier
- `backend/shap_ibm_explainer.pkl` — SHAP TreeExplainer

> **Note:** Training on the full IBM dataset (~24M transactions) may take 30–60 minutes. For quick testing, use `df = df.sample(100_000, random_state=42)` in the data loading cell.

## Step 2: Start the FastAPI Backend

```bash
cd backend/

# Create virtual environment (recommended)
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Start the server
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

The API will be available at `http://localhost:8000`.

> **Mock Mode:** If the `.pkl` files are not found (e.g., before running the notebook), the backend automatically enters **mock mode** and returns plausible random SHAP values. You'll see `⚠️ Running in MOCK mode` in the server logs. The frontend works fully in mock mode.

### API Documentation

Once running, visit:
- **Swagger UI:** `http://localhost:8000/docs`
- **ReDoc:** `http://localhost:8000/redoc`

### API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Health check + model status |
| `POST` | `/api/evaluate` | Evaluate a transaction for fraud |

### Example Request

```bash
curl -X POST http://localhost:8000/api/evaluate \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 1547.89,
    "hour": 2,
    "minute": 15,
    "mcc": 5999,
    "use_chip_Online Transaction": 1,
    "use_chip_Chip Transaction": 0,
    "use_chip_Swipe Transaction": 0,
    "errors_Bad PIN": 1,
    "errors_Insufficient Balance": 0,
    "errors_Technical Glitch": 0
  }'
```

### Example Response

```json
{
  "fraud_probability": 0.8734,
  "prediction": "Fraud",
  "model_mode": "live",
  "shap_values": [
    { "feature": "Amount", "impact": 0.412 },
    { "feature": "Errors?_Bad PIN", "impact": 0.287 },
    { "feature": "Hour", "impact": 0.231 },
    { "feature": "Use Chip_Online Transaction", "impact": 0.198 },
    { "feature": "MCC", "impact": -0.054 }
  ]
}
```

## Step 3: Start the React Frontend

```bash
cd frontend/

# Install dependencies (first time only)
npm install

# Start the Vite dev server
npm run dev
```

Open **`http://localhost:5173`** in your browser.

### Frontend Features

| Component | Description |
|---|---|
| **Live Transaction Feed** | Auto-refreshes every 3.5s with mock credit card swipes |
| **Risk Assessment Card** | Shows fraud probability %, dynamic colored progress bar, verdict |
| **SHAP Explainer** | Horizontal bar chart — red bars = fraud drivers, green bars = safe signals |
| **KPI Dashboard** | Session totals: transactions analyzed, frauds caught, alert rate |

> **Tip:** The frontend includes its own offline mock fallback. Even without the backend running, clicking transactions will show simulated SHAP explanations so you can evaluate the UI independently.

## 🧠 Model Architecture

```
Raw Transaction Data
        │
        ▼
  Preprocessing
  - Strip $, parse Time → Hour/Minute
  - One-hot encode: Use Chip, Errors?
        │
        ▼
   SMOTE (Training only)
   - Oversample minority (fraud) class
   - Balance training set 50/50
        │
        ▼
  LightGBM Classifier
  - n_estimators: 500
  - learning_rate: 0.05
  - num_leaves: 63
  - class_weight: balanced
  - Early stopping on validation AUC
        │
        ▼
  SHAP TreeExplainer
  - Per-prediction feature attribution
  - Global feature importance summary
        │
        ▼
  FastAPI /api/evaluate → React Dashboard
```

## 🔧 Configuration

### Backend Environment

| Variable | Default | Description |
|---|---|---|
| `PORT` | `8000` | Uvicorn port |
| `HOST` | `0.0.0.0` | Uvicorn bind address |

### Frontend Environment

Create `frontend/.env.local` to override the API URL:

```env
VITE_API_URL=http://localhost:8000
```

Then update `App.jsx` to use `import.meta.env.VITE_API_URL`.
